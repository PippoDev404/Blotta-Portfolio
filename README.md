# Blotta-Portfolio
Portfólio desenvolvido para **Daniel Blotta (@blottavisual)**, profissional de **Design, Fotografia e Vídeo**.
O projeto foi criado com foco em apresentar seus serviços, portfólio e pacotes comerciais de forma moderna, além de facilitar a conversão de visitantes em clientes através do WhatsApp.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome

## Funcionalidades

* Layout responsivo
* Cursor personalizado
* Animações de scroll
* Navegação dinâmica
* Portfólio de projetos
* Sistema de abas para pacotes
* Efeitos e animações de hover
* Integração com Instagram
* Integração com WhatsApp
* Mensagens automáticas de acordo com o pacote selecionado

## Estrutura

```text
├── index.html
├── style.css
├── script.js
└── README.md
```

## Pacotes

Os serviços são organizados em quatro categorias:

* **Design:** Starter, Pro e Branding
* **Fotografia:** Essencial, Marca Pessoal e Produto
* **Vídeo:** Reels, Conteúdo e Institucional
* **Empresas:** Business, Premium e Personalizado

Cada pacote possui integração com o WhatsApp, gerando automaticamente uma mensagem com o serviço selecionado.

## Executando o projeto

Não é necessário instalar dependências.

Clone o repositório e abra o `index.html` no navegador ou utilize o **Live Server** no VS Code.
